✦ Gmail AI Summarizer

Configure your Google account connection, AI provider, and topics.

Gmail connection

Grants read-only access so the extension can look at your important emails.

Not connected

AI provider

Your API key is stored locally in this browser (chrome.storage.local) and is sent directly from your machine to the provider you choose below. It never passes through any third-party server run by this extension.

Topics

Each topic becomes a tab in the summary panel. Give the AI a short description of what belongs in each one — e.g. Swimming: "swim practice times, meet schedules, pool closures", or Work: "meetings, deadlines, project updates". Emails that don't match any topic land in an automatic "Other" tab.

Email scan settings

Uses normal Gmail search syntax to decide which emails count as "important".
